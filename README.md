# Test002Stockfish

A browser chess experiment for testing a multi-file GitHub project with:

- HTML
- CSS
- JavaScript modules
- chess.js for legal chess rules
- Stockfish 18 Lite Single WASM for analysis

## Run it

Do **not** double-click `index.html` and expect every browser to allow all module/worker features.

Use a local HTTP server.

### macOS / Linux

```bash
cd Test002Stockfish
python3 -m http.server 8000
